# Витрина

Здесь лежат готовые ролики для публичного сайта на Render. Они собраны
локально командой `python -m app.render_cli "тема"` и закоммичены в
репозиторий намеренно: на бесплатном тарифе нет постоянного диска, поэтому
всё, что не в git, исчезает при каждом деплое.

Рядом с каждым `.mp4` лежит `.json` с метаданными — из него страница берёт
заголовок, хук, тайминги сцен и атрибуцию. Файлы пишет сборщик сам.

Чтобы обновить витрину: собрать ролик локально, скопировать пару файлов из
`out/videos/` сюда и запушить.

Держите папку небольшой — каждый ролик весит 6–16 МБ, а репозиторий не
хранилище видео. Три-четыре штуки для показа достаточно.
