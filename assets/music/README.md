# Фоновая музыка

Положи сюда треки в mp3, m4a, wav или ogg — сборщик подхватит их сам.
Трек для конкретного ролика выбирается детерминированно по теме, так что
одна и та же тема всегда получает одну и ту же музыку.

Пустая папка — не ошибка: ролик соберётся без музыки.

## Где брать лицензионно чистое

- **Pixabay Music** — pixabay.com/music, свободно для коммерции, атрибуция не нужна.
  Через API музыка не отдаётся, качать руками.
- **Free Music Archive** — freemusicarchive.org, смотри лицензию у каждого трека.
- **Epidemic Sound / Artlist** — по подписке, если понадобится библиотека получше.

## Чего не делать

Не бери случайные треки из интернета и тем более из чужих роликов. Это прямой
путь к блокировке канала пользователя, а претензии прилетят сервису.

## Настройки микса

Громкость и затухание заданы в `app/video/music.py`: 0.14 от голоса и фейд
за 3 секунды до конца. Выше 0.3 речь перестаёт читаться.
